# Dormant payment implementation

CertPrep360 is currently a **free product**. The `process-payment` handler is retained for future reference only and must not be connected to the application without a separately reviewed commercial-release change.

The active platform has no payment API Gateway routes, Terraform Lambda module, deployment-package entry, client API caller, or payment-provider SSM parameter. Re-enabling payment requires deliberate additions across those controls, current provider verification review, and product approval.
